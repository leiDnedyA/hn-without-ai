# noai-hn

Here to give you the option to read HN without all 
the AI content. Scans the title of each post 
**and the content** to figure out whether to classify 
it as about AI or not. If it's not primarily about AI, 
it gets added to the list. Otherwise it is not.

Ironically, this project was built with AI coding and 
uses AI to filter out articles about AI. Go figure.

Click **login** to save your Hacker News username in this browser and show a
**threads** link to your replies on HN. **Logout** forgets the saved username.
This is a local preference; it does not sign you into or out of Hacker News.

Set `NEXT_PUBLIC_GA_MEASUREMENT_ID` to a Google Analytics 4 measurement ID to
enable analytics. Analytics is disabled when the variable is not set.
