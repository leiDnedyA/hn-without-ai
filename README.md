# noai-hn

Here to give you the option to read HN without all 
the AI content. Scans the title of each post 
**and the content** to figure out whether to classify 
it as about AI or not. If it's not primarily about AI, 
it gets added to the list. Otherwise it is not.

Ironically, this project was built with AI coding and 
uses AI to filter out articles about AI. Go figure.
